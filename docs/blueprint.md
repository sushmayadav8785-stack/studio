# **App Name**: Rex Host Landing Page

## Core Features:

- Hero Section: Displays the company name, catchy headline, subheadline, key value propositions, and prominent CTAs.
- Marquee: Showcase tech partners with a scrolling banner
- Feature Grid: Displays key benefits like high performance, low latency and advanced security in a grid.
- Control Panel Showcase: Presents a mockup of the dashboard to highlight user-friendly features such as One-Click Plugin Installers, Version Changer and live console access.
- Interactive Pricing: Interactive pricing structure for Minecraft hosting plans including tiers (Starter, Pro, Extreme) and associated benefits.
- AI Configurator: Interactive tool offering users personalized hosting recommendations based on selected criteria (Game, Player Count, Mod Level)
- Competitor Comparison: Showcasing the value by a features comparison between Rex Host and Budget Hosts

## Style Guidelines:

- Primary color: Neon emerald green (#3df27d) for a futuristic and energetic feel.
- Background color: Deep navy (#1e293b) for a sleek, dark mode aesthetic.
- Accent color: Electric blue (#1d9bf0) to highlight interactive elements.
- Body and headline font: 'Inter', a sans-serif font, for easy readability.
- Modern, vector-based icons for feature cards.
- Glassmorphism effects for cards and sticky navigation.
- Subtle hover animations for buttons to enhance user experience.
